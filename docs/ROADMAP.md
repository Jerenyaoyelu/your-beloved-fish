# 小鲸鱼桌宠 · 功能路线图（v0.3 → v1.0）

> 目标定位：**工作助手 + 情感陪伴**，有长期记忆、能自我进化；先本地，后上云（微信/手机）。

## 0. 现状基线（v0.2）

已有：

- 透明置顶桌宠、拖动、冒泡、双击聊天、托盘、开机自启、重启
- 聊天（DeepSeek API）+ 工具调用：待办、提醒、记住事实、查记忆、查时间
- 本地记忆：事实/待办/提醒/摘要/逐轮对话；每 4 轮抽取、每日整理、人设自我补充
- 记忆面板（增删改查）、人设编辑
- 到点提醒、错过提醒启动确认、低余额/充值恢复提醒
- 原创形象、应用图标、皮肤导入（PNG/GIF/JPG）

缺口（本路线图要补的）：

| 缺口 | 影响 |
|---|---|
| 读屏 / 感知 | 不知道你在干什么，只能被动等你说 |
| 文件 / 终端 / 浏览器操作 | 只能"记"，不能"做" |
| 语音（ASR/TTS） | 只能打字，陪伴感弱 |
| 日历 / 邮件 | 工作助手深度不够 |
| 云端 / 微信 / 多端 | 关机就找不到它 |
| 安装器 | 目前是脚本目录，不像"软件" |

## 1. 目标架构

```
┌──────────────┐   localhost HTTP/WS   ┌──────────────────────────┐
│  桌面壳(UI)   │ ◄───────────────────► │  本地能力服务 (Python)     │
│  WPF/PowerShell│                       │  · 工具执行/审批           │
│  气泡/聊天/面板│                       │  · OCR / ASR / TTS        │
└──────────────┘                       │  · 调度(提醒/例行)         │
        │                              │  · 记忆库(SQLite)          │
        │                              │  · LLM 调用/路由           │
        │                              └───────────┬──────────────┘
        │                                          │ (可选)
        │                              ┌───────────▼──────────────┐
        │                              │  云端服务 (ECS/容器)       │
        │                              │  · 同构服务 + Postgres     │
        │                              │  · 微信/企微 webhook       │
        │                              │  · PWA / 推送              │
        └──────────────────────────────┤  · 设备/账号/同步          │
                                       └──────────────────────────┘
```

关键原则：

1. **UI 与能力分离**：桌面壳只负责"画"和"交互"，所有能力走本地服务；以后换壳（C#/Tauri）不动业务。
2. **记忆是资产**：独立存储、可导出、可迁移；桌面和云端共用同一套 schema。
3. **能力即工具**：读文件、跑命令、看屏幕都是"工具"，统一权限与审计，不散落在 UI 里。
4. **工作类任务优先外包**：文件/终端/代码类交给 DSH（ACP/MCP），桌宠做入口、记忆和播报，避免重造 Agent。
5. **默认隐私优先**：读屏/截图/语音默认关闭或需显式触发；原图不落盘。

## 2. 分阶段计划

### P0 · 打地基（约 1 周）

| 事项 | 产出 |
|---|---|
| 本地能力服务 | Python FastAPI 常驻 127.0.0.1，提供 chat/memory/tools/scheduler API |
| 数据迁移 | JSON → SQLite（facts / todos / reminders / summaries / turns / events），保留旧数据导入 |
| 桌面壳改造 | 现有 WPF 界面改为调用本地服务，界面不变 |
| 安装器 v1 | Inno Setup 或 PyInstaller 打包，桌面/开始菜单快捷方式，卸载器 |

**验收**：断网也能启动；记忆读写全部走 SQLite；双击安装包可完成安装。

### P1 · 感知与表达（约 2 周）

| 事项 | 说明 |
|---|---|
| 读屏（手动） | 右键「看看这个」→ 抓前台窗口 → Windows OCR（本地）→ 摘要进上下文；原图用完即弃 |
| 读屏（自动，可选） | 默认关；开启后每 N 分钟仅在"空闲且窗口变化"时抓取；本地 OCR；可在隐私面板查看"最近看过什么" |
| 语音输入 | 全局热键按住说话 → faster-whisper 本地识别（或云端）→ 进聊天 |
| 语音输出 | edge-tts（在线，音色好）/ SAPI（离线）二选一，可开关、可选音色、可配"只读短句" |
| 状态表情 | idle / listening / thinking / speaking / happy 五态；先程序化（缩放/浮动/气泡），后续接 WebM |
| 隐私面板 | 读屏、语音、截图的开关与最近记录 |

**验收**：按热键说话能聊；回复能朗读；「看看这个」能说出当前窗口在干什么。

### P2 · 工作能力（约 2-3 周）

| 事项 | 说明 |
|---|---|
| DSH 接入（首选） | 通过 ACP/MCP 把任务交给 DSH 会话（文件、终端、代码、工作区），桌宠负责发起/播报/记忆 |
| 自建工具（兜底） | 读文件、列目录、搜索、写文件（需批准）、运行命令（白名单+批准）、打开网址、剪贴板、截图 |
| 审批与审计 | 敏感操作弹卡片：允许一次 / 总是允许 / 拒绝；全部写审计日志 |
| 工作区沙箱 | 文件操作限定在配置的工作区；命令在工作区目录执行 |
| 日历/邮件（可选） | Microsoft Graph（OAuth）或 IMAP/CalDAV；早报、会议前提醒、未读摘要 |

**验收**：「帮我把桌面上的报价单总结一下」「跑一下测试并告诉我结果」能完成，且每一步有批准记录。

### P3 · 记忆进化 v2（约 2 周，可与 P1/P2 并行）

| 事项 | 说明 |
|---|---|
| 混合检索 | FTS5 关键词 + 向量（bge-small-zh 本地 / API embedding），按相关性+新近+重要度排序 |
| 结构化记忆 | 人/项目/文件等实体与关系；去重合并、置信度、过期时间 |
| 反思闭环 | 每日/每周总结；提议人设/技能更新（低风险自动、高风险确认）；支持回滚 |
| 记忆浏览器 | 搜索、编辑、删除、导出；"它为什么记得这个"溯源 |
| 主动关心 | 会议前、久坐、待办逾期、长时间未互动等触发器 |

**验收**：聊得越久越"懂你"，但每条记忆都能查到来源、能删掉。

### P4 · 上云与多端（约 3-4 周）

| 事项 | 说明 |
|---|---|
| 云端服务 | 同一套服务容器化上 ECS；Postgres + pgvector；账号/设备注册 |
| 同步 | 服务端权威 + 本地缓存；离线队列；字段级合并，冲突可回滚 |
| 微信 | 优先**企业微信自建应用/机器人**；其次公众号客服消息；**不做个人号 hook**（封号/合规风险） |
| 手机/网页 | PWA 或轻量 Web 聊天，共用记忆 |
| 通知与成本 | 消息限流、模型路由（轻/重）、摘要缓存、预算告警 |

**验收**：电脑关机后，微信里还能找到它、聊到同一份记忆。

### P5 · 产品化（约 2 周）

- 自动更新、崩溃日志（可选上报）、代码签名
- 首次引导：API Key、隐私选项、权限说明
- 设置项分组与迁移；数据备份/恢复

## 3. 优先级建议

1. **P0 先做**：不先拆服务，后面每个功能都会变成 PowerShell 里的补丁。
2. **P1 的「读屏（手动）+ TTS」优先于自动读屏**：陪伴感提升最大，隐私风险最小。
3. **P2 的工作任务优先接 DSH**，自建工具只做轻量兜底（读文件、打开网址）。
4. **P3 与 P1/P2 并行**：记忆是长期资产，越早结构化越好。
5. **P4 最后**：等本地形态稳定、记忆 schema 定型再上云，否则会二次迁移。

## 4. 需要拍板的决策

| # | 决策 | 选项 | 建议 |
|---|---|---|---|
| 1 | 桌面壳技术栈 | 继续 PowerShell / 迁 C# WPF / Tauri | P0 后迁 **C# WPF**（Windows 集成最好）；过渡期 PowerShell 继续用 |
| 2 | 工作类操作 | 自建全套 / 交给 DSH | **交给 DSH 为主**，自建只读工具兜底 |
| 3 | 语音 | 本地 Whisper / 云端 ASR | 隐私优先 **本地**；机器弱再退云端 |
| 4 | 云端 | 自有 ECS / 不用云 | 你有阿里云 ECS，可先小规格跑 P4 |
| 5 | 微信形态 | 企微 / 公众号 / 暂缓 | **企微自建应用**最稳；公众号受客服消息窗口限制 |

## 5. 风险与对策

- **隐私**：读屏/截图默认关，原图不落盘；本地 OCR；记忆可删可导出。
- **权限**：写文件/跑命令必须批准；工作区沙箱；审计日志。
- **成本**：读屏和检索会放大 token；轻模型做摘要、缓存、预算告警。
- **微信合规**：不做个人号自动化；企微/公众号走官方接口。
- **技术债**：PowerShell 长期不可维护，P0 后尽快迁 C#；业务逻辑放服务层，壳可替换。

## 6. 建议的第一个迭代（v0.3）

> 用 2 周做一个"看得见"的版本：

1. Python 本地服务 + SQLite 记忆（P0）
2. 右键「看看这个」→ 前台 OCR → 一句话总结（P1）
3. 回复 TTS 朗读，可开关（P1）
4. 读文件工具（工作区内）+ 审批卡片（P2 的最小片）
5. Inno Setup 安装包（P0）

做完这一版，它就从"会记事的桌宠"变成"能看、能听、能说、能读文件的桌宠"。
